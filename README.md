# yt-video-archiver

`yt2html` saves a YouTube video page as **one self-contained HTML file** for offline use, in the spirit of the SingleFile browser extension: description, chapters, transcript and all comments, readable without YouTube and without an internet connection. It uses [yt-dlp](https://github.com/yt-dlp/yt-dlp); no AI, no browser, no API key.

The video itself and its subtitles are **not** downloaded; download them separately (e.g. with yt-dlp). The page gets the same base name as yt-dlp's default video file name, `Title [video id].html`, so both can sit side by side.

## What the page contains

- **Thumbnail, title, channel** with its subscriber count.
- **Facts:** duration, publication date, views, likes, comment count, and in grey the *Snapshot* date (when the page was made; added by the program, not by YouTube).
- **Full description** (what YouTube hides behind *Show more*) with clickable links, timestamps, `#hashtags` and `@handles`.
- **AI-generated video summary**, if YouTube offers one.
- **Chapters**, with a grey note saying whether they come from the description or were generated by YouTube, and other timestamp lists such as **Walkthroughs**, as plain vertical lists.
- **People mentioned** (photos, names, descriptions) and **Explore the podcast**, if YouTube shows them.
- **Transcript**, already open, split by chapters; as continuous text, with timestamps, or side by side with a translation.
- **License**, if it is not the standard YouTube one (e.g. Creative Commons).
- **All comments**, oldest first, every thread fully expanded, with likes, pinned and creator marks.

Images are embedded in the file and the page needs no JavaScript. It shows in light or dark colours according to the device it is opened on. Not included: the video player, recommendations, YouTube's *Video details* (it repeats the facts).

## Installation

Requires [uv](https://docs.astral.sh/uv/) (it also installs a suitable Python by itself).

```powershell
uv tool install git+https://github.com/mwislowski/yt-video-archiver
uv tool update-shell
```

`uv tool update-shell` adds uv's command folder to `PATH` (once; open a new terminal afterwards). Check with `yt2html --version`.

| Task | Command |
|---|---|
| Update the program and yt-dlp | `uv tool upgrade yt-video-archiver` |
| Remove the program | `uv tool uninstall yt-video-archiver` |

Optional: a JavaScript runtime recommended by yt-dlp for YouTube, e.g. Deno (`winget install DenoLand.Deno`). Without it yt-dlp prints warnings about video formats; they are harmless here, because the video is not downloaded.

## Usage

```powershell
yt2html "https://www.youtube.com/watch?v=..."
```

The page is saved in the current folder (e.g. the folder with your downloaded videos); `-o FOLDER` saves it elsewhere. Always put the URL in quotes: in PowerShell `&` in a URL would otherwise be treated as an operator.

| Task | Command |
|---|---|
| Several videos at once | `yt2html "URL1" "URL2" "URL3"` |
| Videos listed in a text file (see below) | `yt2html -a list.txt` |
| Save into another folder | `yt2html "URL" -o "D:\Videos\Channel"` |
| Make a page again although the video already has one (e.g. for newer comments) | `yt2html "URL" --overwrite` |
| Without comments | `yt2html "URL" --no-comments` |
| Only the first N comments (quick test) | `yt2html "URL" --max-comments 200` |
| Without avatars (smaller file) | `yt2html "URL" --no-avatars` |
| Without the grey Snapshot date tile | `yt2html "URL" --no-snapshot` |
| Page always dark / always light (default: follows the device) | `yt2html "URL" --theme dark` / `--theme light` |
| When YouTube asks to sign in or to confirm you are not a bot | `yt2html "URL" --cookies-from-browser firefox` |
| Also keep the raw data | `yt2html "URL" --save-json` |
| Rebuild a page from saved data (no download; keeps the snapshot date) | `yt2html --from-json "Title [id].info.json"` |
| Versions of the program and yt-dlp | `yt2html --version` |
| All options | `yt2html --help` |

### Transcript versions

`--transcript` takes one or more versions, separated by commas without spaces; they appear on the page in that order.

| Value | Result |
|---|---|
| `plain` (default) | continuous text, without timestamps |
| `timestamps` | one line per caption, each with its timestamp |
| `bilingual:LANG` | like `timestamps`, with YouTube's machine translation into `LANG` (e.g. `bilingual:pl`) in a second column |
| `none` | no transcript |

Examples: `--transcript plain,timestamps`, `--transcript plain,bilingual:pl,bilingual:de`. Each version may appear only once and `none` cannot be combined with others. If a requested translation is not available, the program stops with an error, lists the languages that are, and saves nothing.

### Archiving many videos

For many videos, put their URLs into a text file, one per line, e.g. `list.txt` made in Notepad, and run `yt2html -a list.txt`. Blank lines and lines starting with `#` are ignored, so the list can have comments:

```text
# Season 1
https://www.youtube.com/watch?v=Z8lf5oWKfj0
https://youtu.be/qyqCTMirNWg
```

`-a` can be given several times and combined with URLs in the command; a video listed more than once (also in another URL form) is archived once. The file must be saved as UTF-8 (Notepad's default). The program only reads it, never changes it. Playlist URLs are not supported, in the file or in the command.

**Videos that already have a page are skipped**, so running the same command again only archives what is missing, and an interrupted run continues where it stopped. A page is recognised by the video id in square brackets at the end of its name, e.g. `[Z8lf5oWKfj0].html`: you may rename pages freely (`042 My title [Z8lf5oWKfj0].html`) as long as that part stays. Only the output folder itself is checked, not its subfolders. To make a page again, delete it or use `--overwrite` (the page keeps its current name). `--from-json` always replaces the page.

## Good to know

- Comments take most of the time: YouTube serves about 20 per request, so 10,000 comments take a few minutes. `Ctrl+C` stops downloading them and still makes the page from the comments fetched so far.
- The number of downloaded comments is usually a bit lower than YouTube's count (deleted or hidden comments); the page shows both. A limited download (`--max-comments`) shows as fewer downloaded comments; `No comments.` appears only when the video really has none.
- Comment times are as YouTube showed them on the download day (`3 years ago`); hover over one to see the estimated date. Subscriber counts are rounded by YouTube (`1.23M`); views and likes are exact.
- The transcript is the one YouTube's *Show transcript* opens: the captions of the video's original language, also for auto-dubbed videos. The AI summary is in the language of the video.
- `bilingual:LANG` uses YouTube's machine translation, so its quality varies. YouTube refuses translations requested within about a minute of opening the video, so the program may wait up to a minute (shown on screen) and retries after `HTTP 429`.
- A chapter list in a video description becomes real chapters on YouTube only if it starts at `0:00`, has at least three timestamps in ascending order and each chapter is at least 10 seconds long.
- Typical page size: a few hundred KB up to a few MB for thousands of comments.

## Troubleshooting

- **Fetching fails after it used to work:** YouTube changes often and yt-dlp follows within days; update first with `uv tool upgrade yt-video-archiver`. `yt2html --version` shows the yt-dlp version in use.
- **`Sign in to confirm you're not a bot`, age-restricted video:** use `--cookies-from-browser firefox`. Firefox works best on Windows; Chrome and Edge encrypt their cookies in a way yt-dlp often cannot read.
- **A translation keeps failing with `HTTP 429`:** try again later, or open the video in Firefox with auto-translated subtitles on and use `--cookies-from-browser firefox`.
- **`No transcript: ...` although YouTube shows *Show transcript*:** look for a yt-dlp warning about subtitles and a missing PO token; updating yt-dlp usually helps.
- **`Could not read them ...; using yt-dlp chapters instead`:** the page is made, but without the AI summary, People mentioned and similar sections, and with chapters under a plain `Chapters` heading. Usually temporary; run again with `--overwrite`.
- **`Chapter source unclear: ...`:** the chapters are on the page, only without the grey origin note. Please report the video: YouTube has probably changed something.
- **`FAILED: ... this is a playlist or channel URL`:** pass the URL of a single video.
- **Some avatars are letters:** those images could not be downloaded (or the author has none).
